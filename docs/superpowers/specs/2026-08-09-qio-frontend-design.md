# QIO 前端设计规范（v2 · 2026-08-09）

> 本文档取代预览版设计（旧 `tokens.css` 仅作占位），是本轮 brainstorm 逐点确认后的正式设计语言。
> 原型验证位于 `qio/.superpowers/brainstorm/`（可视化伴侣会话），主原型 `planet3d.html`。

## 1. 设计方向

- **定位**：QIO 是「真正的个人助手」——本地优先、长对话、记忆/知识双域、星球导航。
- **核心审美**：现代极简 + **三渲二（Cel/Toon NPR）** + 星球隐喻。
  - 3D 动画（自转、相机聚焦、视差）承载空间感；
  - 2D 扁平渲染（无写实光照、无纹理噪点）承载克制与高级感；
  - 线条语言（轮廓线、经纬线、融合环）承载精密与科技感。
- **关键词**：透明、线条、融合环、暗紫晶/净白、玫红、三声部字体。

## 4. 星球渲染与交互规范（核心）

### 4.1 球体
- **透明球**：填充近乎全透明（`opacity≈0.05` 玻璃感），背景/星星透出。
- **轮廓线**：跟随相机的细圆轮廓（玫红，不透明度 ~0.8）。
- **细网格**：极淡经纬线（`--link`，低透明度），维持「球」的 3D 可读性。
- 背景：暗色 = 暗紫晶径向渐变 + 星点；亮色 = 净白径向渐变（无星点）。

### 4.2 话题点
- 话题 = 贴合球面的**扁平圆点**（沿表面法线朝向的圆片，随球旋转、侧面变扁）。
- **大小绑定话题本体**（权重 = 片段数/活跃度），点半径 `0.028 × weight`。
- **最小间距**：同簇点角距 ≥ 0.095 rad，禁止圆点相交。
- 半球剔除：转到背面自动隐藏。

### 4.3 融合环（SDF）
- 每个话题 3 圈环，圈级半径 `[0.14, 0.22, 0.34] × weight`。
- **融合**：球面 SDF（`acos(dot(p, topic))` 角距离）+ **Smooth Minimum**（k=0.16）并集外轮廓——重叠处内弧消失、外轮廓连成有机曲线（细胞/等高线融合）。
- **粗细**：内粗外细，像素全宽 **内 10px / 中 6.5px / 外 4px**（半宽 5.0 / 3.25 / 2.0）。
- **恒定像素宽**：按 `|f|/|∇f|`（像素距离）描边，融合交界处宽度不变。
- **抗锯齿**：GPU `fwidth` 1px 边缘 AA；球面片元着色器实现（无锯齿、贴合球面、近大远小自然）。
- 透明度：内 0.62 / 中 0.44 / 外 0.28（由内到外渐淡）。

### 4.4 交互
| 交互 | 规范 |
|---|---|
| 点击话题点 | 相机 320ms `easeInOutCubic` 聚焦到点（**距离 2.25**，已接近目标朝向时自动缩短到 0.6×）+ 星球旋转使点居中 + 点放大 1.3× |
| 点击后**环波** | 三圈环**从内到外依次暗淡再恢复**（每圈错峰 0.16s，高斯型暗波 0.10s 宽，总时长 ~1.2s）；无额外水波 |
| 拖拽/缩放 | OrbitControls 阻尼；聚焦补间结束后恢复可拖拽 |
| 自转 | 空闲时缓慢自转（0.1 rad/s）；聚焦期间暂停 |
| 复位（收起） | 180ms 收势 + 280ms 整体淡出后卸载（不再走「缩回全景」那条路径，见 §8 的 2026-09-14 二次修订） |
| 坐标标签 | 聚焦点下方等宽标签：`话题 #0004 · 地区 A · 12.4°N · 33.8°E` |

## 5. 对话页组件规范

- **状态条**：SSE 连接点、模型三态徽标（native/text/unsupported）、budget、`tok` 读数（等宽）。
- **消息流**：轮次分隔（TURN + 时间戳等宽）；用户气泡（玫红底白字，右圆角）；助手气泡（elevated 底 + 边框）；工具卡（折叠/展开 JSON）；记忆注入标签（玫红虚线胶囊）。
- **空状态**：衬线大字「今天想聊点什么？」+ 状态点 + 引导。
- **输入区（Composer）**：话题名（衬线）+ 锚点片段（等宽）+ 斜杠命令提示 + 输入框（规范见 §7）+ 记忆强度滑块（等宽读数 0.38）。
- **悬浮球（PlanetDock）**：右下微缩星球（透明球 + 三圈融合环 + 圆点，SVG/低帧率 3D），点击展开全屏星球。

## 6. 设置页组件规范

- 分区：**凭据 / 偏好** 两个 Tab。
- **凭据卡**：名称 + 类别/scope 标签 + 连接状态 + 掩码密钥（只写不读）+ 预算进度条 + 审计条数 + 操作（测试/编辑/删除-危险色）。
- **表单**：使用 §7 输入组件；密钥用 password + 等宽。
- **偏好**：模型端点（三态适配）、强制继续开关、记忆强度默认值、冷话题阈值（90d）。

## 7. 输入组件规范（已确认）

- 令牌：高 `38px`，圆角 `10px`，内边距 `10px 14px`，字号 `14px`/行高 1.5；背景 `--bg-inset`，文字 `--text-strong`，占位 `--text-muted`。
- 状态：默认 1px `--border-subtle` → 悬停 `--border-strong` → 聚焦 **1px `--accent` + 3px `--accent-soft` 柔光**（背景提亮）→ 错误 **1px `--danger` + 红柔光** + 等宽错误行 → 禁用 opacity .5。
- 变体：单行 / **等宽**（数据、密钥、URL）/ **多行 textarea** / **自定义下拉**（非原生：关闭态=输入框+箭头，展开态=elevated 浮层、悬停玫红柔光、选中玫红+✓，支持 Esc/Enter/Space/方向键）/ 标签 + 等宽帮助文字。
- 亮暗双主题同一套令牌。

## 8. 动效规范

| 项 | 值 |
|---|---|
| 相机聚焦 | 320ms，`easeInOutCubic`，短距离 0.6×（2026-09-14 修订：原 650–800ms 被判定为过长；后又在动画统一时定为 320ms） |
| 星球居中 slerp | 补间期间 dt*7 |
| 环波 | 每圈错峰 0.16s，暗波 σ=0.10s，总 1.2s，恢复 |
| 悬浮/呼吸 | 星球轻微浮动 sin(0.4t)·0.04 |
| 帧率目标 | ≥60fps（环静态缓存；动效仅改 alpha/相机） |
| 减少动画 | `prefers-reduced-motion: reduce` 时：CSS 动效由 `base.css` 归零；**JS 相机补间也必须压到一帧**（`usePlanetScene` 自己读该偏好） |

> 2026-09-14 修订：常用低频场景（设置、星球、侧栏、菜单、弹窗）以「短而平稳」为准——
> 出现与消失控制在 140–280ms（分层令牌见 §8.1），星球相机移动 320ms，边栏开合后的重新居中与宽度过渡同时发生（不再等动画结束再补一次）。

> 2026-09-14 二次修订（星球展开/收起，演示版）：原实现用「整层淡入 + 相机从远景拉近」两条时间线，
> 收起则是「淡出与相机后撤同时跑」，实测总时长 225ms——用户反馈过快、且过渡不连贯。现在改为：
> **展开**＝先 140ms 铺底盖住聊天，再用 420ms 让内容淡入与相机小幅收敛同时结束（相机一开始就在接近最终构图，
> 不再出现"远景小球明显放大"）；**收起**＝先 180ms 收势（沿视线轻微后撤 + 星球降到 25% + 面板退场），
> 再 280ms 整体淡出，淡出结束才卸载（实测 531ms）。减少动画时跳过两段、直接卸载（实测 9ms）。
> 演示开关：`?planetdemo=slow` 把这条时间线放慢 3 倍，便于逐帧观察。

### 8.1 分层动画参数（2026-09-14 第二次修订）

令牌落在 `tokens.css`（沿用既有 `--dur-*` / `--ease` 命名，只补缺失档位）：

| 场景 | 令牌 | 时长 | 说明 |
| --- | --- | --- | --- |
| 按下反馈 | `--dur-press` | 80ms | 按下立即开始，不等待请求；位移 1px |
| 开关 / 选中 | `--dur-toggle` | 150ms | 选中同时用文字/字形/描边区分，不只靠颜色 |
| 菜单 / 小型弹窗 | `--dur-menu` | 170ms | 出现立即可见随后减速；退出同为 170ms |
| 设置页打开 | `--dur-page-in` | 220ms | 整页淡入 + 2px 上移，内容同帧可见 |
| 设置返回 | `--dur-page-out` | 170ms | 对话页短淡入，不做整页位移 |
| 侧栏开合 | `--dur-panel` | 210ms | 与 210ms 重定位补间**同时**进行，不再串联 |
| 星球打开 | `--dur-planet-backdrop` + `--dur-planet-in` | 140ms 铺底 + 420ms 淡入/收敛 | 2026-09-14 演示版：用户反馈原 300ms「过快、不连贯」，改为两步；一开始就接近最终构图，不再从远景小球放大 |
| 星球关闭 | `--dur-planet-settle` + `--dur-planet-out` | 180ms 收势 + 280ms 淡出 | 2026-09-14 演示版：先轻微后撤并把星球降到 25%、面板退场，再整体淡出后卸载；减少动画时直接卸载 |
| 话题聚焦 | `--dur-focus` | 320ms（短距离 0.6×） | 已接近目标朝向时自动缩短 |
| 浮窗贴靠 | `--dur-snap` | 220ms | 只在松手贴靠时过渡，拖动直接跟随 |

> 星球开合的落地细节（收起阶段 `pointer-events: none`、打开序号与旧回调、就位时跳过空补间）见 §12.5.1。
> 实测关闭总时长为 **473–627ms**（同一套编排在多次测量间有波动，按区间报告，不声称精确值）；
> 减少动画下 5–43ms 直接卸载。任务 05 未改动聚焦距离 2.25、球体结构与融合环。

曲线：`--ease-out`（打开，快速起步后减速）与 `--ease-in`（关闭，先慢后快、不拖尾）。
同一时间发生的淡入、位置调整与侧栏展开并行执行，不串行叠加等待；状态完成一律由状态本身决定，
不用固定等待时间判断「动画结束」。

浮层收尾规则：菜单退出期间 `opacity/visibility/pointer-events` 一起收（不拦截点击、不参与 Tab）；
模态弹窗退出期间**保留遮罩拦截**（避免误点落到下层危险操作）但内部不可交互，退出结束整块从 DOM 移除。
减少动画或时长为零时直接跳过退出阶段，功能不依赖动画事件。

动画偏好：`html[data-motion]`（`standard` / `reduced`），用户可选跟随系统 / 标准 / 减少动画，
存 `localStorage(qio-motion)`。CSS 与星球相机补间读同一份结果，运行中切换立即生效；
减少动画时移除大幅缩放、旋转与持续自转，保留必要的短淡入与明确的文字状态。

## 9. 无障碍

- 亮色主色对比度 ≥4.5:1（`#c51b7d` 净白底 ≈5.4:1）；暗色强调文字用 `#e878bd`。
- 键盘可达（自定义下拉 Esc/Enter/方向键）；聚焦态清晰可见。

## 10. 技术实现要点

- 星球环：three.js `ShaderMaterial`（WebGL2），逐片元 `acos` 角距离 + smooth-min + `fwidth` AA；uTopics/uWeights 数组 uniform。
- 环宽恒定：`dp = |f|/|∇f|`（像素距离）阈值化，非场强阈值。
- 性能：环在 GPU 上，JS 每帧仅更新相机/rotation/dim uniform。
- 话题点：CircleGeometry 圆片 + Canvas 高分辨率贴图（256px、无 mipmap、各向异性采样），`renderOrder` 分层。
- 平面 2D 参考实现（环形并集/行进方格）见 brainstorm 会话的 `ring-fusion-example.html`（4x 超采样 + 分层合成可达 120fps）。

## 12. v2.1 交互修订（2026-08-09 晚，用户确认）

> 本修订基于可交互概念演示（`float-layout-demo-*.html`）逐轮确认，覆盖对话页布局与设置页交互的再设计。

### 12.1 对话页
- **移除顶部状态条**：SSE 状态点、活跃标识、budget、tok 等一律不再出现在顶部横条。
- **token 使用数**：作为**每条消息底部的下缀**（等宽小字，如 `09:42:11 · tok 1,204`）。
- **暗色模式切换**：移入**设置页 → 偏好**（不再有全局切换按钮；跟随系统 + 设置内手动）。
- **设置入口**：右上角浮动 **⚙** 按钮（见 12.2）。

#### 12.1.1 对话内容列与输入区（2026-09-14 修订）

- **同一个内容列**：回答与用户消息都在一条**居中内容列**（最大 860px）内——回答在列内左对齐、
  用户消息在列内右对齐，不再分别贴到窗口两端；长文仍受 `--measure`（68ch）限制，不铺满整屏。
- **输入区位置**：固定在**这条内容列的正下方**（宽 860px，居中；中等窗口为右侧星球入口留出通道；
  `≤899px` 改为整宽贴底）。输入区仍然**不可拖动**（沿用 2026-09-12 的决定），因此没有「用户保存的浮动位置」
  可保留；星球入口与设置入口的浮动位置与贴靠关系不受影响，「还原默认布局」入口照旧可用。
- **输入区外观**：默认**中性边框 + 较轻阴影**；聚焦时只把外框变成强调色一层，
  内层 textarea 不再同时叠边框 + 光晕。
- **底部留白**：消息流底部按输入区高度预留空间（ResizeObserver 跟随），滚到底时最后一条内容停在输入区上方。
- **回到最新**：上翻阅读时出现「回到最新消息（N）」，点击才滚动回最新并恢复跟随；
  自动滚动可被滚轮/触屏中断。新消息最多一次 170ms 入场，历史消息直接显示。
- **状态表达**：只表达可观察到的阶段——已提交且还没有任何助手内容时显示「已提交，等待模型响应…」，
  有增量内容后由流式气泡表达「正在生成」；等待动画只在回答附近播一次，任务列表用静态「运行中」标记。

### 12.2 浮动窗口体系（对话页）

> **2026-09-12 修订（实现为准）**
> - **输入框（Composer）不再可拖动**：固定在对话内容列正下方（2026-09-14 起由右下角改为与内容列对齐的居中位置；最高频控件要有稳定肌肉记忆）。
>   本节中所有「输入框可拖动 / 输入框贴边隐藏 / 输入框收起方向 transform」的描述作废。
> - **token 下缀改为按 turn 归属**，且**只在开发者模式显示**（后端只提供单 turn 总 token，
>   没有 input/output 分解就不显示分解数字）。§12.1 中「每条消息底部显示累计 token」作废。
> - **设置页信息架构改为一二级分区**（外观 / 对话与记忆 / 模型与联网 / 工具与权限 /
>   数据与维护 / 凭据 / 高级）。「窗口」并入**外观**；服务端 tuning 收进**高级**。
> - **星球页右侧面板宽度不再固定 340/640px**，改为响应式（≥1200：`clamp(340px,32vw,480px)`，
>   管理模式 `clamp(360px,46vw,640px)`；<900px 变为覆盖式抽屉）。§12.5 中的固定宽度作废。
> - 贴靠隐藏的**可发现性**：淡化最小值由近乎消失改为 `opacity .35` + 保留轮廓。

- 两个浮动组件：**话题星球入口**、**设置入口（⚙）**（输入框固定，不参与浮动）。
- 均可**拖动**；松手自动贴靠：
  - **话题星球入口：贴边**（吸附最近边，保留拖动时的垂直/水平位置）；
  - **设置入口（⚙）：贴角**（吸附最近角）；
  - **两者互斥**：贴靠时互相避让，不重叠（贴角自动跳过被占角；贴边沿边微调）。
- **只有真正拖动（位移 > 阈值）才贴靠**：单击/微抖动不改变位置、不写入持久化。
- **窗口 resize 后保持贴靠关系**：贴右边 → 距新右边缘保持同一 margin，而不是留在旧的绝对坐标；
  未贴靠的组件被钳制回可视区。
- 贴靠动画：四方向统一缓动（`cubic-bezier(.22,.8,.24,1)`，~0.3s）；定位一律用像素 `left/top`（避免 `auto` 不可过渡）。
- **贴靠隐藏（可配置）**：设置页 → **外观 → 窗口行为** 中可分别开关「话题星球入口 / 设置入口」是否允许贴靠隐藏；开启后贴靠即自动淡化，**hover 展开、移出再隐藏**。
- **设置是整页**：点 ⚙ 打开**全屏设置页**（非浮动面板），页面内可返回对话。

### 12.3 设置页交互
> **2026-09-12 修订：** 一级分区改为 外观 / 对话与记忆 / 模型与联网 / 工具与权限 / 数据与维护 / 凭据 / 高级；
> 反馈按分区独立（不再共用一个 notice），成功/失败/警告/信息用不同语义色。
> 已配置的凭据（如博查 API Key）**留空保存不等于清除**：需显式「替换」或「清除」。
> 下面关于凭据卡片与 toast 的交互保持不变。

- **新建凭据 = 独立子卡片**：平时折叠，点「＋ 新建凭据」才展开表单。
- **测试连接结果 = toast**：浮现 2.6s 后自动淡出消失，不再常驻错误条。
- 其余（凭据/偏好 Tab、掩码密钥、预算条、编辑换钥语义等）保持 v2。

### 12.4 技术要点
- 浮动组件定位：初始化与拖动全程使用像素 `left/top`，不依赖 `transform` 定位（保证过渡可动画）。
- 拖拽：pointer + mouse 双事件 + document 级 move/up（兼容 WebView/桌面）；位移 >3px 判定为拖动（避免与点击冲突）；贴靠按钮不触发拖动。
- 互斥贴靠：矩形相交检测 + 候选位置（边/角）按优先级选取。
- 组件状态：`dataset.edge/corner/docked` 记录贴靠状态；拖起时释放占用。
- **贴靠隐藏实现**：隐藏态由 `fw-hidden` 类 + 各组件 CSS 控制；**hover 展开 / 移出再隐藏由组件 CSS `:hover` 实现**（浏览器按真实几何逐帧命中，无 JS 事件时序问题）；输入框收起方向按贴靠边（top/left/right/bottom）各写一条 transform，只留 10px 细边，其余组件用 opacity 淡化。
- **窗口管理（设置页 → 窗口）**：三个浮动组件（话题星球入口/设置入口/输入框）的贴靠隐藏开关，读写共享 `floatingState[id].hideEnabled`；偏好独立持久化到 `qio-float-hide`（组件未挂载时也能保存），「还原默认布局」调用 `resetFloatPositions()`（清空位置 + 关闭全部隐藏）。

### 12.5 星球页话题边栏（2026-08-10，用户确认）
- **默认收起**：星球页右侧 340px 话题边栏初始为收起态，仅在最右缘保留一枚竖向展开钮（圆角胶囊 + 箭头，hover 玫红柔光）。
- **展开方式**：点击展开钮，或**点击任意话题点**（聚焦的同时自动展开边栏）。
- **收起方式**：点击边栏左缘的收起钮（箭头反向）；收起后焦点话题与详情状态保留。
- **画布重对焦**（2026-09-14 修订）：边栏开合会改变画布宽度（flex 重排）与画布中心；
若存在焦点话题，则**与 210ms 宽度过渡同时**跑一段 210ms 短补间，把焦点话题重新居中到新画布中心
（不重复触发环波）。旧规则「等 ~380ms 动画结束后再补一次 360ms 移动」会让用户看到明显两次位移，已废弃。
- **点击非焦点话题**：星球 slerp 旋转居中 + 相机 320ms 聚焦（距离 2.25）**同时进行**；详情请求与动画并行，不等移动结束才请求。

#### 12.5.1 打开落点、加载与关闭（2026-09-14 任务05 修订）
- **打开落点**：起点没有变化时回到「上次浏览的话题」（同次运行期内存，不落盘）；
  起点明确变化（换话题或换片段）时以新起点为准，浏览记忆不覆盖它。
- **打开构图**：挂载时直接把相机放到接近最终构图（`primeCamera`），有落点就一次到位做朝向收敛，
  不再「先完整总览、再完整聚焦」。已经在目标构图时 `go()` 直接落状态，不空跑一段锁住拖动的补间。
- **加载反馈**：数据未回来时显示「正在加载话题…」；失败显示原因 + 重试（不拿空球冒充完整内容）。
  懒加载 chunk 期间由 `PlanetBoot` 立即铺底并显示「正在打开星球…」，入口按下即 `scale(0.96)`。
- **关闭**：收势 180ms（轻微后撤 + 星球降到 25%）→ 整体淡出 280ms → 才卸载（实测 488–608ms；
  减少动画 5–59ms 直接卸载）。收起阶段整层 `pointer-events: none`，不再拦截点击与焦点。
- **开合竞争**：父级给每次打开分配序号并作为 `key` + `seq` 传入；关闭回调带序号回来，只认当前序号。
  关闭动画中再次点入口会换一个全新层，旧层的迟到回调不会关掉它。

#### 12.5.2 详情区结构与三个概念（2026-09-14 任务05）
- **三段式**：顶部固定（页签 + 「话题」标题 + 搜索）、中部可滚动、底部固定操作区。
  中部再分两块：话题列表自己滚且高度封顶 42%，详情正文占满剩余空间自己滚 ——
  话题很多时详情不会被挤到折叠线以下；底部操作区在滚动区之外，实测不覆盖正文。
- **三个概念分开写**：面板顶部固定展示「浏览的话题 / 选中的片段 / 已生效的起点」三行，
  浏览与选中不等于起点已改变；「已生效的起点」取自会话（服务端返回）状态，不做本地猜测。
- **空状态分级**：加载中、加载失败（独立错误区 + 重试）、无片段（说明「还没有可接续的历史位置」）、
  无摘要（「（无摘要）」）、空话题分别表述，失败不写成「无数据」。

#### 12.5.3 话题点的可发现与可选中（2026-09-14 任务05）
- **悬停标签**：指向话题点时显示简短名称（单行省略，指针右侧），移开即消失，不让标签常驻遮挡。
- **选中标记**：选中话题有持续可见的环（面向相机、随点一起隐藏到背面），不依赖一次性的环波动画；
  列表 `aria-selected`、星球选中环与详情标题三处状态一致。
- **命中范围放大**：精确 raycast 未命中时，回退到「屏幕上距指针 ≤ 16px（点击）/ 14px（悬停）」的可见点，
  不必精确点中像素中心；背面点不参与命中。
- **键盘与触屏**：话题列表项可聚焦（`role=option` + `tabindex=0`），Enter/Space 与点击同效；
  触屏单次轻点即选择并加载详情，不依赖悬停。
- **Esc 分层**：边栏是后打开的一层，Esc 先收边栏，边栏已收起才收起整个星球。
- **辅助网格减弱**：经度线由 45° 间隔改为 60°，赤道/纬线透明度 0.35/0.18 → 0.22/0.1，经线 0.13 → 0.07；
  只减弱装饰，球体结构、融合环与聚焦距离 2.25 不变。
- **管理面板**：知识/实体读取失败显示原因 + 重试（不伪装成「暂无记录」）；
  「暂无记录」与「没有匹配」文案不同，并提供「清除筛选 / 清除搜索」一键回退。

## 13. v2.2 修订（2026-09-14，任务 04/05：设置、审批、状态真实性、无障碍）

### 13.1 审批弹窗（默认回答顺序）

信息按「用户做决定所需要的顺序」排列，技术细节默认折叠：

1. **它想做什么**：一句人类语言（优先取工具描述，而不是后端 `kind` 枚举名）。
2. **它会访问什么**：具体行为标签——会联网 / 会读取文件 / 会修改文件 / 会执行命令 / 会使用凭据；只读操作显示「只读」。
3. **会改变什么**：把 `副作用` 枚举翻成人话（不修改任何数据 / 只读取 / 会写入或修改数据 / 会删除或覆盖已有数据）。
4. **为什么需要**：解释或原因；与第 1 条重复时不重复显示。
5. **验证了吗**：`已验证`（附测试摘要）或 `未验证`（子 agent 型工具没有自动测试报告）；**拿不到测试信息时不显示这一行**，不假装已验证。
6. **高级详情**（默认折叠）：策略指纹、逐条测试结果、raw params。

按钮层级：拒绝＝secondary（中性描边）；批准＝primary（品牌色）；**高风险操作给批准按钮降调为中性实心**，
避免品牌色让「允许」看起来像推荐。高风险批准不因 Enter 直接触发。
**Esc 不做决定，但按最上层处理**：收起窗口（＝稍后处理）、保留待审批项，并由「有 N 项操作等待确认」入口重新亮出来——
旧规则「Esc 完全无效」会让用户只能被迫做决定，已废止（2026-09-14 任务 04）。

### 13.5 确认调度：不打断编辑，但不藏待办

后台任务请求确认（`APPROVAL_REQUIRED`）时的调度规则：

1. **用户没在输入** → 立即弹出审批窗口（直接相关的确认不延迟）。
2. **用户正在输入**（焦点在输入框 / 文本域 / 可编辑区，含凭据表单） → **不自动弹出、不抢焦点**；待审批项入队，
   页面亮出常驻入口「⚠ 有 N 项操作等待确认」（顶部居中，避开右下角浮动组件），任务继续等待，用户主动点开才显示窗口。
3. 窗口提供三个出口：**拒绝**、**稍后处理**（只收起窗口，保留待办，与批准/拒绝明确区分，外观比拒绝更轻）、**允许此次操作**。
4. 窗口收起或队列清空后，**焦点归还被打断的元素**（实测回到凭据表单输入框，未提交内容不丢）；重复事件不产生重复窗口，也不重复计数。
5. 待确认项不允许出现「看不见」状态：只要队列非空且窗口没显示，入口就必须可见；入口用 `mousedown.prevent` 保持原焦点不被按钮抢走。

### 13.2 设置页保存模型

- 自动保存的参数（开关、数字步进、下拉选择）在分区标题下标注「修改后自动保存」，并在请求期间显示「保存中…」，成功后给结果、失败给错误；不得只写控制台。
- 需要一起提交的参数（搜索条数、正文字符预算、SearXNG 地址、凭据）由显式「保存」按钮统一提交，并在分区标注这一区别。
- 功能不可用时要说明原因与出路（例如「当前没有可用的联网搜索通道：请开启免密钥搜索，或配置博查密钥 / 自建 SearXNG 实例」），不能只把控件摆成禁用。

**设置页的移动与数字控件（2026-09-14 任务 04 收尾）**

- 进入设置：整页只做一次短淡入（`220ms`），**不做整体位移**——旧实现的 `translateY(2px)` 会让整页轻微上浮，被判为「整个设置页来回移动」。
- 切换分类：只对右侧内容做一次很短（`170ms`）的淡入，左侧分类栏与页头**不得移动**；面板继续用 `v-show` 保留，切分类不会重建表单、不会丢掉未提交的草稿。
- 数字控件（`QNumber`）：支持 `unit` 属性把单位显示在数值旁（如「24 小时」），不让用户回头去分区标题里找单位；加减按钮宽度 `22px → 30px` 并加 `touch-action: manipulation`，触屏命中更容易。

### 13.3 状态真实性（起点与停止）

- **起点切换必须同步可见消息**：`从这里继续` 成功既要更新锚点，也要重新拉取该起点的消息；
  否则界面仍显示上一个话题的对话（实测：后端已换到 0 条消息的空话题，界面仍显示上一条话题的 16 条）。
  SSE `ANCHOR` 同理，但任务运行中不重载（避免擦掉正在流式输出的内容）。
- **停止按钮按真实状态说话**：提交后、服务端运行标识（`turn_id`）到达前，按钮不是可用的「停止」而是「准备中…」；
  拿到运行标识后才显示「停止」，取消过程中显示「正在停止」。不得出现「看起来能按、实际按不动」的按钮。

### 13.4 无障碍与键盘

- 聊天页第一个键盘焦点位是 `.skip-link`「跳到输入框」：消息流里每条消息都有复制按钮，
  实测按 Tab 的前 8 个停靠点全是它们（长对话里要按几十次才到输入框）。跳过入口平时不可见，聚焦时出现在左上角。
- 输入框具备 `id="composer-input"` 与 `aria-label`；焦点环、弹窗焦点陷阱与减少动画维持 §9 与 §8.1 的约定。

## 14. v2.3 修订（2026-09-15，第四阶段：视觉统一 / 交互收口 / 动效语言）

> 本节的完整版本已独立成文：`docs/superpowers/specs/2026-09-15-visual-language-phase4-design.md`（规范 v3）。
> 这里只登记**对既有条款的修订**，避免同一套规则两处维护。

第四阶段不新增后端能力、不改信息架构，只做「把已经建立的能力用同一套语言表达出来」。

### 14.1 修订 §8 / §8.1（动效）

§8.1 的「分层动画参数」表保持不变（`--dur-press` 等令牌仍然可用），但其**取值来源改为三层令牌**：
高频 `--mo-1-*`、中频 `--mo-2-*`、低频 `--mo-3-*`；旧 `--dur-*` 降级为别名。
新增曲线集 `--ease-1` / `--ease-1-out` / `--ease-2` / `--ease-2-out` / `--ease-3-in` / `--ease-3-settle` / `--ease-3-out`。

修订单条：

- **星球展开不再只是「铺底 + 淡入」**，改为三段连续过程（入口激活 → 体量展开 → 场景接管），
  退出严格反向；入口小球 = 全屏 Planet 的压缩态，两者是同一个对象的不同尺度状态。
  演示开关 `?planetdemo=slow` 的语义不变（把该时间线整体放慢便于逐帧观察）。
- 新增位移令牌 `--shift-1/-2/-4/-8/-panel`：组件里不再允许写裸位移数值，否则 reduced-motion 无法整体降级。
- **低频关键动作的「优雅弹性」定义**：不是明显 bounce，而是有生命感的非线性收束 ——
  起步不僵硬、中段有推进感、结尾略带柔和阻尼（实现上用 `--ease-3-settle`：单次约 3% 过冲后收紧）。

### 14.2 修订 §9（无障碍 / reduced-motion）

旧规则「reduced-motion 时把所有动效时长归零」**废止**：它让状态变化全部瞬切，连续性丢失。
新规则：保留必要的淡入淡出（时长压缩到约 90ms）与全部状态文字，去掉位移、缩放与弹性
（`--shift-*` 归零、`--ease-3-*` 退化为标准曲线）；JS 相机补间读同一份 `html[data-motion]` 走最短路径；
功能不依赖动画事件；系统偏好仍可被设置里的「标准」显式覆盖。

### 14.3 新增：材质与组件语言

- **晶体玻璃**（`--glass-*`，类 `.qio-glass`）用于 Planet 周围浮层、轻量信息卡、关键确认层与少量局部悬浮 UI；
  不使用在所有消息、全部按钮、所有列表项、长文本主体与高频输入表单上。
  它必须是高透、低雾、有边缘厚度与极轻冷暖边分离的透明介质，不是「深色毛玻璃 + 一道高光」。
- **组件原语收敛**（`frontend/src/styles/base.css`）：Button / Card / ListRow / Toolbar / Tag / StateBadge /
  InlineEdit / Feedback / Floating / Confirm + 过渡工具类。新功能不再自带视觉语法。
- **反馈四级**（字段 / 组件 / 任务 / 全局），成功更短更局部、失败更清晰更持久。
- **浏览器原生 confirm / alert / prompt 全部替换为 QIO 确认层**，按危险程度分档。
- **默认阅读、按需编辑**：Knowledge / Entity / Topic Detail / Settings 复杂区域默认阅读态，
  编辑在局部发生，退出即恢复。
