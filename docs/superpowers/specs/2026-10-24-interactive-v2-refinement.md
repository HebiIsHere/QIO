# 互动页 v2 第二迭代设计（2026-10-24）

## 目标
在现有互动页 v2 上完成用户确认的第二轮改版：
1. 对话悬浮在板面上，工具栏固定在输入区上方，不抬高板面；
2. 卡片按真实尺寸自动进入/退出详细状态，图片保留极端比例的兜底入口；
3. 板面改为白底主题色点阵纸；
4. 补执行记录和提交详情，删除旧的重叠入口。

## 已确认决策

### 悬浮对话与工具栏
- 对话卡固定在板面底部居中，宽度与输入胶囊一致。
- 板面保持完整高度，不被对话压缩；对话覆盖在板面上。
- 对话卡内部从下到上：输入胶囊 → 工具栏按钮 → 展开的消息区。
- 对话展开时消息区向上增长，工具栏和输入胶囊位置不移动。
- 收起时消息区消失，工具栏和输入胶囊保持可见。
- 对话最大高度保留至少 220px 板面可见。
- 点击板面、拖动卡片、选中对象时自动收起对话；不停止回复、不清草稿、不丢附件、不改排队。

### 工具栏
- 常驻按钮：添加、撤销、重做、标注、书签、提交给 QIO。
- 搜索从底部工具栏删除，使用全局栏搜索。
- 选中对象后的分组、排序、连线、移出组等操作追加到同一排；数量多时进入“更多”。
- “提交给 QIO”只提交板面；输入框发送/停止只负责聊天，两个按钮永不合并。
- 提交状态只显示一个图标按钮，不显示文字状态；悬停有说明，点击打开提交详情。
- 提交详情包含：可见材料、书签、未提交改动、提交范围、错误、历史摘要。
- 执行记录入口：从原意图和成果卡的“更多”打开；无成果时从原失败意图打开。
- 执行记录包含：确认材料/版本、授权范围、实际操作、真实结果、部分完成、失败原因、自动/手动重试、恢复/撤回。

### 卡片自动详细
- 删除普通卡片的“展开预览”主按钮。
- 普通卡片按真实卡片尺寸判断，不使用板面缩放：
  - 进入：宽度 ≥ 420px 且高度 ≥ 280px；
  - 退出：宽度 < 360px 或高度 < 240px。
- 拖动、键盘调尺寸、组缩放、撤销恢复、重新加载使用同一判断。
- 进入/退出详细状态不改变卡片尺寸、不改变参与状态。
- 始终保留滚动位置、PDF 页码、表格工作表、文本/代码阅读位置、图片方向。
- 图片保持原图比例，使用方向/面积规则自动判断；极端比例在当前未达到自动状态时显示右上角小眼睛“查看完整图片”；点击进入详细状态，关闭回简洁；不恢复旧“展开预览”按钮堆。
- 自动状态的详细内容使用卡片自身渲染，不另开右侧预览。

### 点阵纸背景
- 亮色：白色底 + 主题色点阵。
- 暗色：深色表面 + 同一主题色点阵，不强制白底。
- 点阵间距 24px，点直径 1px，主题色约 8% 透明度；暗色略高。
- 点阵随板面平移和缩放。
- 卡片、组框、悬浮对话覆盖点阵。
- 所有颜色使用现有 var(--*) 令牌及其透明度派生，不硬编码。

### 旧入口清理
- 删除：IntentBatchTray、IntentStatusPopover、IntentWorkbench、DemoIntentEntry、ChatDock。
- 替换后删除：SubmitCluster 的旧提交详情 UI、IntentPreviewCard/ImpactConfirmDialog 的旧链确认 UI。
- 不删除后端账本和执行事实；只删除旧界面。
- 不保留旧版兼容入口；开发数据可重置。

## 不在本次范围
- 不合并 main、不打包、不发布。
- 不实现真实模型联网验收；仍按项目约定使用 fake/mock provider。
- 不改对话页视觉与交互。
- 不改后端 schema，除非为执行记录读取发现必须新增只读字段。
