# Updater（应用内一键更新）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: 按任务顺序执行，每个任务先写失败测试再实现。

**Goal:** 让已安装的 QIO 在应用内完成「检查 → 下载 → 校验 → 安装 → 重启」，更新源为 GitHub Releases。

**Architecture:** Tauri 2 官方 updater 插件（Rust 侧发请求，不动 CSP）+ process 插件负责重启；前端只有
`services/updater.ts` 一处调用插件，`stores/updater.ts` 持有状态机，设置页只渲染状态；发布侧由
`build_installer.ps1`（签名 + 生成 latest.json + 落 dist/）与 `publish_release.ps1`（gh 上传资产）承担。

**Tech Stack:** Tauri 2.11 / Rust / Vue 3 + Pinia + TypeScript / vitest / PowerShell。

**Spec:** `docs/superpowers/specs/2026-09-22-updater-design.md`

## Global Constraints

- 不静默下载、不静默安装：下载与安装都必须是用户点击的结果。
- 不放宽 CSP（更新请求在 Rust 侧）。
- 私钥不进仓库、不进日志、不进构建产物；缺私钥必须**构建失败**。
- 前端颜色只用 `var(--*)`；文案不得把"检查失败"写成"已是最新"。
- 验证命令：`cd frontend; npx vue-tsc --noEmit; npm test`；Rust：`cargo check`。
