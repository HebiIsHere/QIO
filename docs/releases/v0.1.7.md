## 首次引导（欢迎页）重做

- 引导改成七步：欢迎 / 连接模型 / 认识你 / 偏好 / 目标 / 追问 / 核对并完成。
- **核对之前什么都不写**：所有输入只存在本地，走完最后一步、在清单上确认后才一次性写进去；
  中途关掉就等于没填过，重新打开是空白。
- 清单上可以**逐条修改、逐条删除**；删掉的不会写进去。
- 「认识你」不再暴露"画像知识 / 实体卡"这些内部概念；「偏好」四个维度（详略、语气、解释方式、协作方式）各自都能选预设，也能选**「其他」自己写**。
- 「目标」改成自由填写（不再给固定选项），每条都会新建一个话题；整步可以空着。
- 「追问」按你写下的描述现问两个问题，可跳过；跳过的不进清单，回头补答的会进清单。
- **新用户必须先配好可用密钥**才能离开"连接模型"这一步；主页已有内容的老用户可以随时关掉整场引导。
- 引导写下的信息现在**真的会被后续对话用到**：画像知识挂到"你"这个锚点上，来源、经营范围、记录时间在知识页都能看到。

## 版本更新弹出规则

- 「刚更新到这个版本的人，无论如何展开一次欢迎页」改为**一次性跨越**：只有从低于 0.1.7 的版本升到 0.1.7 或更高时才弹一次；此后 0.1.8、0.2.0 都不再弹。

## 记忆与知识

- **已结束**：阶段性信息（"最近在做…"）和目标都能标记为"已结束"——不再当作当前状态，权重降低，但仍然可以被相关对话与记忆检索找到。
- **话题结束**：已结束的话题离开星球主视图，进单独的「已结束」分组，搜索与记忆检索仍然可达。
- 知识条目显示**来源 / 适用范围 / 时间**，可按来源筛选，并能在知识页改适用范围（全局或只在某个话题里生效）。
- **自我信息只有一份**：改称呼时信息整体跟着走，旧称呼记为曾用名，从对话里学到的其他称呼会并进来，不再新长出一张卡。

## 修复

- 引导新建的密钥现在会带上"主循环"用途标签——没有用途标签的密钥在 QIO 里任何角色都选不中，会导致对话与追问都用不了模型。
- 「有没有配好模型」改为按**可用凭据**判定（启用中、有合法用途、预算未用尽），被禁用/已撤销/无标签的密钥不再算数。
- 设置齿轮不再因为"贴边隐藏"在启动瞬间就把自己藏起来。
- 入口星球的尺度只在球布局就位后计算，并在画布尺寸变化时重新对齐——修掉"星球越开越小"。

## 已知限制

- 追问与"模型推测出的待确认内容"目前只做到提问；从描述里自动提炼待确认条目尚未接入。
- 升级弹窗的门槛写死为 0.1.7（一次性）；后续若要再打扰一次，需要提升该门槛。
