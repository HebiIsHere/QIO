# QIO v0.1.6

三处改进：更新能自动适配 VPN、工具失败的容忍度提高、过程提示不再重复。

## 安装

在应用内「设置 → 数据与维护 → 更新 → 检查更新」即可升级（0.1.5 及以上支持）。

## 这一版改了什么

### 1. 更新自动适配 VPN（多用户分发重点）

以前更新请求只认环境变量，导致"系统代理模式"的 VPN（Clash / v2rayN / Shadowsocks / 脉动VPN 等）
用不上；而系统里若残留一个**指向已关闭代理**的地址，更新会一直等、不报错。

现在每次检查更新前都会重新判断，顺序是：

1. 环境变量 → 2. `%APPDATA%\qio\updater-proxy.txt` → 3. **Windows 系统代理** → 4. 直连

关键行为：

* **零配置跟上常见 VPN**：VPN 以"系统代理"方式工作时，QIO 自动使用同一份设置；
* **TUN / 全局模式的 VPN** 本来就不需要配置，走直连；
* **采用之前先测连通性**（最长 0.5 秒）：不可达就不用，并清除进程内的代理变量 →
  最坏结果是"这次不用代理"，不会卡在一个没人监听的地址上；
* 会话中途开关 VPN 不需要重启 QIO。

不支持：只提供自动配置脚本（PAC）的代理（不解释脚本，记为未使用代理）、只有 socks 的地址、
需要用户名密码的代理。

### 2. 工具失败容忍度提高，到上限先问不直接停

* 判定口径统一为**同一个工具累计失败**（以前按"工具＋参数完全相同"分桶计数，
  模型每次换个参数重试就永远攒不到阈值）；
* **15 次**开始警告，**30 次**拦下这次调用并**询问你是否继续**；
* 你选择继续 → 该工具计数**清零**，本轮接着跑；选择停止 → 本轮结束（由你决定，不是系统替你停）。

### 3. 过程提示不再重复

同一批工具调用里，如果已经带了模型自己写的执行叙事，就不再单独显示「◈ 过程」气泡；
没有叙事时，模型的前置说明照旧显示（不丢信息）。

## 已知限制

* 安装包未做 Authenticode 代码签名，安装时 Windows 可能提示「已保护你的电脑」；
* 不做差分更新（每次下载完整安装包，约 108MB）、不做回滚；
* PAC / 浏览器插件式 VPN / 需认证的代理无法自动适配（任何非浏览器程序都不行）。
