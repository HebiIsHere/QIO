# QIO v0.1.3

补丁级更新：加了**应用内一键更新**，之后再发新版就不用手动下载安装了。
功能与 v0.1.2 相同（执行叙事层、工具卡、审批），没有界面或行为上的其它变化。

## 安装（这一次仍要手动装）

1. 下载 `QIO_0.1.3_x64-setup.exe`（约 107MB）；
2. 运行安装包（若 Windows 提示「已保护你的电脑」，点「更多信息 → 仍要运行」）；
3. 设置 → 凭据里填好自己的 API Key。

**⚠️ 为什么这一次还要手动装**：v0.1.2 里没有更新器代码，它不可能"自己知道自己该更新"。
装上 0.1.3 之后，从**下一版**开始才能在应用内点按钮更新。

## 这一版新增：应用内更新

入口：**设置 → 数据与维护 → 更新**。

* 显示当前版本，一个「检查更新」按钮随时可点；
* 启动后 10 秒静默检查一次，之后每 24 小时一次（设置里可关）；
* 发现新版本时可点「下载并安装」，有下载进度；
* 下载完成后由你决定什么时候「立即重启」，不静默重启；
* 安装过程中应用会短暂关闭并自动重启，这是安装器的正常行为。

安全上做了三件事，说明白：

1. 更新包必须通过 **minisign 签名校验**才会被安装，校验失败直接放弃（不会装未签名的包）；
2. 更新只从 `https://github.com/HebiIsHere/QIO/releases` 取；请求由程序本体（Rust 侧）发出，
   与网页侧的网络策略无关；
3. 全程需要你点击，**没有**"后台自动下载安装"这回事。

已知限制（如实列出）：

* 安装包仍未做 Authenticode 代码签名，安装时 Windows 可能仍提示「已保护你的电脑」；
* 不做差分更新：每次更新下载完整安装包（约 107MB）；
* 不做多通道（beta/stable），也不支持回滚到旧版本。

## 校验

```
SHA256(QIO_0.1.3_x64-setup.exe) = __SHA256__
```

## 从源码构建

```powershell
# 更新签名只在你本机（私钥与口令不进仓库）
$env:TAURI_SIGNING_PRIVATE_KEY_PATH     = "C:\Users\zxy\Documents\Front agent\dist\qio-updater.key"
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = "<口令>"
pwsh -File scripts/build_installer.ps1                     # 取模型 → sidecar → 打包 → 签名 + latest.json
pwsh -File scripts/publish_release.ps1 -Version 0.1.3      # 上传到 GitHub Releases
```
