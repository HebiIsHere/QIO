# QIO v0.2.10

本版发布 **QIO 整体改造第一至第四阶段**的整合结果，并包含一次完整 CI 暴露出的线程生命周期缺陷修复。

- 0.2.3 – 0.2.9 的功能与已修复项继续适用。
- 阶段契约与交接：`docs/qio-refactor-contract.md` §1–§14；验证台账：`docs/qio-verification-ledger.md`；
  进度与已知限制：`docs/status.md` P69–P72。

## 一、统一提示词、消息组装与工具契约（P69）

- 模型可见固定文案集中到 `backend/src/agent/prompts.py` 单一来源；统一消息组装
  （system 规则 + 模式规则 + 结构化上下文块），用户原文与媒体内容按真实部分传递。
- 工具结果统一结构化协议（status / code / data / facts），schema 与本地校验同源；
  记忆滚动覆盖、摘要与注入边界按契约收口。

## 二、独立后台维护与「记忆待确认」（P70）

- 后台知识维护独立调度：变化计数（20 条或等待 30 轮触发）、快照推进、失败退避、单轮互斥；
  与工具输出清理、工具记录保留、自动化建议彼此独立。
- 维护动作合并 / 格式整理 / 独立提问；保留条件、归属、确定程度与全部来源；
  不同类别、归属或确定程度不自动合成更强认识；旧否定词降权与 revoke 路径退出调度。
- 「记忆待确认」入口、维护记录与安全恢复：预览、逐条 / 整批撤回、保护用户后续修改；
  后台问题与回答不进入主对话消息、摘要与轮次。

## 三、互动模式接入完整主循环（P71）

- 点击「提交给 QIO」后由同一个主循环受理（同一 TurnManager / 模型 / 工具循环），
  不再使用独立理解模型与整份 JSON 重写修复；旧理解记录只读兼容。
- 12 个板面工具：查看、读取、提出/更新意图、等待补充、建卡/改卡/移动/分组/排序/链接、结束意图；
  板面身份、提交、原话题、目标版本与授权由程序绑定，普通模式不暴露板面工具。
- 意图授权按目标与结构化影响范围校验；对象真实版本 + 写前 CAS；operation_key 幂等；
  写入冲突只暂停受影响步骤；完成声明核对完整操作账本、等待、冲突与依赖。
- 等待事项与原提交持久关联，回答后自动续作，不需要重新提交；部分失败保留成果；
  问题只在对话中呈现一次，允许不回复的轮次不强制补答案。

## 四、子任务、凭据、工具开发闭环与引导（P72）

- 子任务保留控制字段 `_qio_subtask`：`credential_ref` 必填，model / context / evidence_ids /
  budget 严格校验并先剥离再传业务参数；真实区分排队、运行、完成、部分完成、失败、取消、预算耗尽；
  完整结果保留并分页读取；通知可靠排队去重；结果回到原任务与原话题续作。
- 可用凭据目录工具（不返回密钥），QIO 自主选择适用凭据与模型，尊重用户指定、权限与上限；
  模型凭据与业务服务凭据分开；旧 `credential_key` 在兼容层归一化，冲突双参拒绝。
- 工具开发闭环：完整版本摘要进入模型可见内容；测试 / 注册 / 真实条件验证分开记录，
  模拟测试与注册不能声明「真实可用」；已放弃任务只读复用材料，禁止写入/测试/提交；
  工具可暂停恢复；受限子进程明确不是安全沙箱。
- 自动化建议结合完整需求、实际结果与已有工具判断，可为空、拒绝后无新依据不催问；
  建议不是开发授权；首次引导最多两问、可空、可跳过、失败不阻塞。

## 五、可靠性修复（完整 CI 暴露）

- 修复 HeavyWork 线程生命周期缺陷：旧 shutdown 不等待执行中的工作线程就返回，
  随后关闭共享 SQLite 连接，工作线程继续使用已释放连接，导致 Windows access violation /
  Linux SIGSEGV。现在 shutdown 等待工作线程真正结束，活跃计数由工作线程侧 finally 维护
  （取消 await 不提前算作结束），测试与关闭路径在关闭连接前排空工作线程。
- 修复 5 条旧去重测试未适配「提交需注入主循环受理器」与 text_license 旧夹具的问题。

## 六、验证

- 完整 CI（`feat/qio-refactor-p4` → main 前一版）：run 39540110401，10 个 job 全绿
  （backend py3.11 / py3.12 / windows、frontend、docs、rust 两平台、frozen worker、install e2e、ci dedup）。
- 本地全量：4640 tests / 0 failed / 0 errors / 51 skipped。
- D 独立验收：57/57 独立契约测试、414 定向回归、620 广域回归、真实界面 19/19；
  离线评估与阶段一基线一致（无退化）。

## 七、已知限制

- 真实模型与真实凭据下的端到端质量未验证（本版验证使用 fake / 种子数据）。
- 自动化建议当前没有独立前端入口；工具停用/恢复当前仅程序 API。
- 旧理解链测试以退役口径 skip（替代覆盖为 P3/P4 套件）；旧理解读取/重试路由仅历史兼容。
- Windows 原生窗口安装体验与发布后升级链路未在本版重新做真机验收。
