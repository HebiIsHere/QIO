# QIO v0.3.0

本版发布 0.2.10 之后的发布前修复链（模型可靠性、UI/互动一致性、设置可靠性、死代码清理、
合并前集成验证），并首次完成 Windows 候选安装包与真实服务验证。0.2.10 及更早版本的功能与
已修复项继续适用。

- 完整验证记录：`docs/release-step6-native-validation-20261029.md`
- 进度与已知限制：`docs/status.md`
- 安装与运行：`docs/SETUP.md`

## 一、模型与服务可靠性

- 同一凭据下不同模型的连接不再相互关闭：adapter 按「凭据 + 模型」分槽位缓存，运行期不关闭
  仍可能被使用的连接，退出时统一释放；缓存与暂留均有上限。
- 并行后台派生工作各自持有本批模型配置；准备连接期间修改用途只影响下一批。
- 模型目录、用途候选与真实调用对连接可用性判断一致（状态、启用、验证、预算、密钥可读）；
  新增「未验证」「密钥不可读」等明确原因；目录只读本地事实，不联网。
- 「日常对话」改为一次性整体保存并在目录中显示真实生效目标，任一用途失败则整批回滚。

## 二、UI 与互动一致性

- 关闭行为按最新有效选择生效：旧响应不再覆盖新选择，桌面壳同步串行化；保存失败回到最近
  一次真实生效值。
- 没有独立模型调用路径的用途（写代码 / 研究 / 视频 / 语音 / 向量 / 自定义标签）不再提供
  独立模型选择，历史配置只读展示并可清除。
- 用途候选按模型能力判断：明确缺能力禁选并说明，能力未知可选但标注「能力未确认」。
- 互动意图执行记录按服务端真实记录显示为默认折叠的可读记录（状态、尝试时间线、逐项结果、
  结果入口）；确认 / 恢复 / 重试后无需手动刷新即出现，无真实完成证据不显示「已完成」。
- 互动页直接进入或刷新后，确认并执行的记录会自动出现，不需要先切到普通对话页。

## 三、设置可靠性

- 同一区域不同设置的保存互不取消；迟到响应、失败回滚、连续修改都以真实已保存值为准。
- 迟到的初始读取不覆盖较新编辑、保存值与生效摘要；失败反馈按设置保留。
- 模型获取按当前配置与请求身份归属：旧配置的发现结果不写库、不覆盖新结果；成功 / 空列表 /
  业务失败 / 网络异常都有明确反馈，失败可单独重试且不重复创建连接。
- Key 保存重试复用请求身份（同身份同内容幂等、同身份不同内容拒绝），提交中重复点击只发一次。
- 搜索结果给出真实命中总数，可分页查看并定位第 9 条与最后一条。

## 四、清理与集成

- 清理七项已无生产入口的死代码及对应旧测试 / 失效文档指向，受保护链路未动。
- 合并前完成六项集成验证，发现并最小修复两个阻塞（互动结果入口读取回退权威账本；提交轮
  程序消息不再渲染为普通用户气泡）。

## 五、Windows 安装包与真实服务验证

- 用脚本既有完整链路从干净检出构建 0.3.0 Windows 安装包（内置模型、自带 Python 运行时、
  后端 sidecar、卸载助手、NSIS 安装包、更新签名与清单）。
- 安装版实测：全新安装与首次启动、内置运行时与模型真实加载、检索命中、托盘隐藏/恢复、
  真正退出无残留、0.2.10→0.3.0 覆盖升级数据保留、静默卸载默认保留用户数据。
- 更新：安装版「检查更新失败可见、不伪装已是最新、失败后仍可用、重启正常」通过；
  应用内更新使用 minisign 签名校验。
- 已知边界（如实说明，不影响本版发布决定）：
  - 真实厂商模型调用在本轮验证时被服务方拒绝（Command Code 401、DeepSeek 402 余额不足），
    真实厂商成功路径与返回质量**未验证**；产品链路已用受控假厂商验证。
  - 真实看图、互动恢复路径、首次引导全流程、关闭询问弹窗点击、外壳级重启、双实例并存
    **未验证**。
  - 本安装包未做 Windows Authenticode 代码签名（与既往版本一致）；应用内更新签名独立校验。

## 六、升级与安装

- 已安装 0.2.10 及更早版本的 Windows 用户：应用内检查更新会下载本版，校验更新签名后安装；
  用户数据与设置保留，数据库按既有迁移前进，二次启动幂等。
- 全新安装：运行 `QIO_0.3.0_x64-setup.exe`；卸载默认保留用户数据，可在卸载向导中显式选择
  删除应用数据。
- 系统要求与运行方式见 `docs/SETUP.md`。

## 七、验证与已知限制

- 发布前完成完整后端 / 前端 / 类型 / 文档 / 第三方声明 / Rust / 安装 e2e 的 CI 矩阵与本地全量测试；
  运行结论回填在 `docs/status.md` 的发布台账。
- 已知限制与保留项：停止轮正文不落库（保留停止终态与重试）、意图执行记录依赖历史读取与
  续作轮事件、模型发现只增不删、模型级验证不提升连接级验证状态、搜索「查看更多」为本地分批
  展示、受限子进程不是安全沙箱。详见 `docs/status.md` 与 `docs/release-step6-native-validation-20261029.md`。
