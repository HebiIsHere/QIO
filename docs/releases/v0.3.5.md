# QIO v0.3.5

本版是 0.3.4 之后的功能版：互动板面换成**无限点阵画布** —— 空板就能向四个方向连续平移，
可以在远离原点的位置建卡、连线，保存重开后仍然找得到。0.3.4 及更早版本的功能与修复继续适用；
窗口框架（0.3.2 的 20px 自绘圆角、三模式、poll 穿透）与底部操作区（0.3.4 的常驻把手 /
线框弧长揭示 / 玻璃面板 / 工具栏 rail）不变。

- 安装与运行：`docs/SETUP.md`
- 逐里程碑记录与边界：`docs/status.md`
- 已知限制见文末

## 一、无限点阵画布

旧板面是「有限滚动模型」：内容撑出一块有限区域，靠容器滚动查看。浏览器不接受负滚动量，
所以空板向左 / 上平移会立刻碰到边界，卡片坐标也被迫夹在非负区间（拖到负坐标时整块板面
会被平移回原点，连带改掉无关卡片的坐标与撤销记录）。

本版把它换成「视口 + 世界层」：

- **唯一视图状态**是 `Viewport { x, y, scale }`。视口自己裁切画面，内容层只做一次
  `translate(x, y) scale(scale)`（`transform-origin: 0 0`）。空板与有内容的板走同一条路径，
  四个方向都能连续平移，没有「纸张尽头」。
- **板面坐标有符号**。拖动一张卡跨过原点只改这张卡；独立卡片的坐标、更新时间与撤销记录
  都不受影响（旧的整板重定位已从正式交互路径移除）。
- **点阵纸铺满视口**：由视图决定原点与间距，100% 缩放时仍是 24px 点距，保留既有主题色与
  疏密；缩得很小时按 2 的倍数合并点避免糊成一片，相位用取模收口，往返跨过零点不跳格。
- **板面外围留白、1px 边框与内层圆角去掉**：点阵从顶部全局栏下方一直铺到窗口底部。
  桌面窗口自身的圆角、全局栏、卡片与浮层的样式不变。

## 二、新卡落点与「查看全部」

- 工具栏「添加」与**双击空白处建卡**共用正式创建逻辑（同一份默认内容、参与状态、编辑入口
  与撤销行为）。双击卡片 / 关系标签 / 把手 / 菜单或浮层不会穿透建卡；完成一次拖动后浏览器
  补发的双击也不会误建卡。
- 新卡落在**当前未被浮层遮挡的可用区域**里：平移到 (-8000, -6000) 附近时，新卡就出现在眼前。
  可用区被占满时从视野附近向外找空位，不会被远处一张孤立卡带走。
- 新增**「查看全部」**（底部工具栏常驻按钮 + 更多菜单）：按当前可展示卡片与分组的实际外框
  计算包围盒（含负坐标；收起组用折叠后真正显示的外框；已删除与隐藏对象不参与），
  放进扣掉遮挡后的可用区并留出可辨认卡片边缘的余量。
  - 两张远卡需要低于 25% 才能同屏时，如实给出那个更小的适配比例，并把它作为后续缩放的
    下限 —— 下一次滚轮不会跳回 25%。
  - 空板回到初始视野与 100%；单卡居中且不被异常放大。
  - 只改查看位置：卡片坐标、选中状态与连线记录都不改写。
- 视野按板面缓存（只存 x / y / 缩放，与板面内容的保存状态分开）。重开远坐标板面时恢复上次
  视野；缺少有效视野时用「查看全部」初始化，不会打开一片空白。

## 三、坐标换算与手势

- 屏幕 ↔ 板面换算统一走 `interactive/viewport.ts`，统一传**原始视口矩形 + 完整视图**，
  不再有「已扣滚动量」的配套函数（那是旧模型下容易把偏移算两次的来源）。
- 尺寸把手、连接点与端点锚点这些**定尺寸浮层**改为「板面锚点 × 缩放 + 视图偏移」：
  缩放会改变把手位置，但屏幕命中尺寸不变（25% 时仍抓得住）。
- 手势分工不变：拖空白平移、空格 + 拖框选、拖卡片移动、拖连接点建关系。
  平移 / 缩放只改查看状态：不产生板面保存、不进撤销栈、不触发提交给 QIO。
- 搜索定位、书签定位与预览定位改用同一套视图差量，定位后目标进入当前可用区
  （底部聊天打开时也能看见）。

## 四、工程与验证

- 新增 `infinite-canvas.test.ts`（14 例）与 `infinite-canvas-save-reopen.test.ts`（4 例）；
  旧模型下依赖滚动量 / 整板重定位的断言按用户可观察行为改写，保留坐标精度、手势与数据
  完整性检查。
- 本地窗口验收（真实 Edge + 真实后端）：空板左上平移 → 负坐标建两卡 → 连线填关系 →
  保存 → 关闭重开 → 查看全部 → 点中原关系，全部通过；保存前后卡片坐标与关系端点 ID
  逐字段一致；查看全部适配比例 0.1253（低于 25%），再滚一级 0.1456 未跳回。
- 顺带修掉一个**换行符敏感的测试断言**：它依赖源码里精确的换行与缩进，在 LF 工作树通过、
  CRLF 工作树（Windows 上 `text=auto` 的默认检出）失败。改成按标签结构判断。

## 五、升级与安装

- 已安装 0.3.1 – 0.3.4 的 Windows 用户：应用内「检查更新」下载本版，校验更新签名后安装；
  用户数据、设置与数据库迁移保留，二次启动幂等。
- 全新安装：运行 `QIO_0.3.5_x64-setup.exe`；卸载默认保留用户数据，可在卸载向导中显式
  选择删除应用数据。
- 回退开关（0.3.2 起，无需重装）：`QIO_WINDOW_FRAME=dwm` / `native`；`QIO_PASSTHROUGH=none`。

## 六、已知限制

- 本轮板面改动只覆盖互动板面；记忆星球未改动。
- 无限画布下「意图预览」的拖动边界改为跟随当前视野（旧的固定画布边界在无限画布下没有意义）。
- 视野缓存存在本机；换机器或清空本机存储后，远坐标板面首次打开会用「查看全部」初始化。
