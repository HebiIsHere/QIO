# QIO v0.1.0

第一个可分发版本：Windows 桌面安装包，**内置 fp32 中文嵌入模型**，开箱即用（目标机不需要 Python）。

## 安装

1. 下载 `QIO_0.1.0_x64-setup.exe`（106.8MB）；
2. 运行安装包。若 Windows 弹出「已保护你的电脑」，点「更多信息 → 仍要运行」（当前未做代码签名）；
3. 首次启动会把内置模型复制到 `%APPDATA%\qio\models\bge-small-zh-v1.5\`（一次性，约 90MB）；
4. 打开「设置 → 凭据 → 新建凭据」，填入你自己的 API Key（支持自动识别服务商与模型），即可开始对话。

**环境要求**：Windows 10/11 64 位。Win11 自带 WebView2；Win10 若缺少 WebView2，安装阶段会联网下载。
**不需要**：Python、Node、uv 或任何其它运行时（后端是打包好的单文件程序）。

## 这一版有什么

### 本地优先的记忆与知识

- 话题 / 片段 / 知识 / 实体四层结构；对话按话题组织，星球页可视化浏览（WebGL 星球，含话题、知识、实体三块面板）；
- 向量召回**内置模型**：`bge-small-zh-v1.5` fp32（512 维，CPU），不需要联网下载、不需要配置；
- 记忆封块：按轮数与**单段长度**分段（设置页可调），长度只是兜底，分段不等于任务完成；
- 摘要与索引是**可重试的派生任务**：模型失败或进程中断不会让对话不可用，恢复后自动补齐。

### 历史接续（本轮重点重构）

- 「从这里继续」不再报错：同一个话题已有进行中的片段时，会在一个事务里封存旧段、建立接续段，并记下来源；
- 点击历史**只登记意图**，输入区明确显示「下一条消息将从「…」继续」，发送前可以取消，不产生空片段；
- 一轮对话的归属（属于哪个话题 / 哪个片段）在提交时就固定：之后切换话题、改选历史都不会再搬动已经提交的消息；
- 队列顺序有保证：先提交的消息保持它原来的位置，后提交的才走新的接续路径。

### 界面与提示

- 会话底部三块（知识候选卡、兼容模式提示、话题切换提示）不再被输入框遮住，按钮可点；
- 确认框按 Esc 可关；关闭后焦点回到原处；
- 更新后新打开的页面不再显示上一次留下的错误提示与排队信息；
- 凭据被暂停 / 失效会在对话页说明并提供恢复入口；
- 不支持 3D 的环境下，星球降级说明是独立卡片，不再叠在聊天内容上。

## 已知限制（如实列出）

- **语义分段仍是观察项**：容量与「明确开工指令」会实际分段，语义/嵌入相关的阶段判断只记录建议、默认不切分，也没有经过独立标注数据的校准；
- 进程重启后**排队中的消息**不会自动恢复（队列未持久化）；
- 旧数据里没有来源记录的片段只能作为「同话题背景」，不享受路径隔离；
- 安装包未做代码签名；也没做首启向导（首次配置需要自己进设置页填 Key，会给出提示与入口）；
- 模型来源与许可证：`bge-small-zh-v1.5` 由 BAAI 发布（MIT），ONNX 转换版来自社区仓库 Xenova；安装目录下的 `LICENSE-BAAI-bge-small-zh-v1.5.txt` 与 `NOTICE.txt` 是完整声明。
