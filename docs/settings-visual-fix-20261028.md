## 4. 删除的解释文字（第 3 类）

规则：删「为什么这样设计 / 我们怎么保证 / 机制如何运作 / 与控件重复 / 同句重复」的段落；
**保留**安全与危险提示、错误与失败原因、限额/范围/单位/默认值语义、状态词、许可与第三方/BYOK 合规说明。

- 常规：分区说明 4 段、行说明 7 条、贴靠说明 2 条、滚动指示条动态 hint（含节点与索引字段）。
- 联网搜索：分区说明、保存机制提示、通道描述句、未配置兜底句。
- 记忆与整理：分区说明、按组保存提示、分档/启用/立即整理行说明。
- 工具与权限：分区说明 3 段、工作区默认值说明（改为 placeholder 保留语义）。
- 关于与更新：更新说明 1 条（BYOK / 许可 / 第三方声明全保留）。
- 模型与服务面板内的重复状态句（F 处理，见其报告）。
- 搜索索引里的说明文字**保留**：那是搜索结果里的描述元数据，不是页面正文。
