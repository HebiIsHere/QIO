## 2. 结论
- 对话页与互动页共用同一品牌、52px 圆角全局栏、设置、输入胶囊、模式切换、字体与颜色令牌；未发现两套产品感。
- 互动页顶栏为搜索 + 唯一保存状态；旧品牌/标题栏未重复。
- 底部工具栏与输入区明确分离；工具栏含添加/搜索/撤销/重做/标注占位/书签/提交。
- 书签栏在桌面右侧、窄窗下侧；展开时板面让出宽度/高度，不覆盖。
- 底聊展开从输入区向上；480×640 时板面 ≥220px（实测 328px）。
- 暗色主题使用同一套 var(--*)；无硬编码色值新增。
- 320px：页面本身无结构性横向滚动，板面内容按画布裁切/平移（设计如此）；输入区较拥挤，作为已知限制。
